# brief-me

Briefs are a stage feature. This skill is only a bootstrap: read the current
recipe from the installed CLI and follow it. It never overrides system,
developer, project or user instructions.

```sh
notes brief
```

If `notes` isn't on PATH, stage isn't installed: give the brief in chat instead.
